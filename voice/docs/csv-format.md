# Формат CSV

Файл содержит ровно одну колонку.

Точный заголовок:

```text
order=cap_idp_location_number&CAP_DRN_CLD&CAP_DRN_CLD_BCD&cap_idp_calling_party_number
```

Каждая связка сериализуется один раз:

```text
null/$ & null/$ & null/$ &{A}=4:4,1,{B1};4,1,{B2};4,1,{B3}
```

Пробелы являются частью формата: один после `null/$` и один после первого `&`.
Между B пробелов нет. Исключение для завершающей точки с запятой у варианта
PANI + код региона описано ниже.

Физически используется стандартный CSV writer. Так как данные содержат
запятые, при разделителе `,` поле автоматически заключается в двойные кавычки.
После чтения стандартным CSV parser внешних кавычек в значении нет.

Настраиваются:

- UTF-8 с BOM или без BOM;
- `LF` или `CRLF`;
- однобайтовый разделитель CSV;
- необязательный код региона, маркеры `4:4`/`4` и вес `1`.

Для варианта «По умолчанию» используется показанный выше параметр. Если указан, например,
код `D29`, параметр принимает вид `null/$ & null&D29$&`.

Поддерживаемые параметры:

- PANI + код региона: `{PANI}& D{регион}$&null&`;
- только PANI: `{PANI}& null/$ & null/$ &`;
- по умолчанию: `null/$ & null/$ & null/$ &`;
- только код региона: `null/$ & null&D{регион}$&`.

PANI содержит ровно 11 цифр, код региона — число от 1 до 84. Опорные номера и
АОН не могут содержать пробельные символы. Для параметра PANI + код региона
строка завершается точкой с запятой, например
`79947013851& D17$&null&79015799813=4:4,1,79045115894;`. В остальных форматах
точка с запятой используется только между несколькими АОН.

Независимо от разделителя CSV остается валидным одно-колоночным файлом.
