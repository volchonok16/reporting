# Симметрика

Simmetrika (рабочее название в коде и на сервере — canvas-studio).

Платформа совместного проектирования интерфейсов — реализация технического задания «ТЗ: платформа совместного дизайна интерфейсов (аналог Figma)».

Главный принцип проекта: **весь код собственный, внешних зависимостей нет**. Единственный сторонний файл — шрифт Inter (`apps/web/fonts/inter`, лицензия SIL OFL 1.1): он поставляется вместе с редактором, чтобы макеты выглядели одинаково на любом компьютере. В репозитории нет ни одного npm-пакета: сборка, dev-сервер, UI, рендер и тесты написаны на встроенных возможностях Node.js и браузера. Подробности — в [ADR 0001](docs/adr/0001-stack-and-dependencies.md).

## Быстрый старт

С сервером (вход, файлы на сервере): `npm run build && npm run server`, затем http://127.0.0.1:8080. Развёртывание на VPS — [docs/DEPLOY.md](docs/DEPLOY.md).


Нужен только Node.js 22.13 или новее (проверить: `node --version`).

```bash
npm run dev        # редактор на http://localhost:5173
npm test           # тесты (node:test)
npm run build      # сборка в dist/
npm run preview    # просмотр сборки
npm run typecheck  # проверка типов, если на машине установлен TypeScript
```

`npm install` не нужен: устанавливать нечего.

## Что уже работает

- Холст: панорамирование (пробел, колесо, трекпад), масштаб 1–25 600 %, отсечение невидимого.
- Инструменты (панель внизу холста): фрейм, секция, прямоугольник, эллипс, многоугольник, звезда, линия, стрелка, изображение, текст, рука; Shift и Alt при рисовании.
- Векторы: перо, редактирование точек и кривых, булевы операции (объединение, вычитание, пересечение, исключение — фигуры внутри остаются редактируемыми), «Сплющить», «Обводку в контур», маски.
- Скругление углов маркерами прямо на холсте (с Alt — один угол); ресайз фрейма с Mod не двигает содержимое.
- Выделение по правилам Figma: дети фреймов верхнего уровня, группы целиком, вход двойным щелчком, глубокое выделение с Mod, рамка выделения.
- Перемещение с привязками и направляющими, перенос в фрейм и между фреймами, перестановка внутри auto layout, дублирование с Alt.
- Изменение размера (Shift — пропорции, Alt — от центра), поворот за углы, ограничения (constraints).
- Auto layout как CSS flexbox: фиксированный размер, по содержимому, заполнить, **проценты и fr-доли**, min/max в px и %, перенос, распределение «между / вокруг / равномерно», абсолютные дети.
- Текст: разные стили внутри одного текста (шрифт, начертание, размер, цвет, B/I/U/S, индексы), редактирование прямо на холсте с выделением мышью; выбор шрифта с поиском и превью (шрифты компьютера), реальные начертания; списки, абзацы, обрезка многоточием; переносы, авто-ширина и авто-высота, интерлиньяж, межбуквенный интервал, регистр, выравнивание.
- Заливки: цвет, линейный и радиальный градиент с редактором точек, изображение (заполнить / вписать / растянуть / замостить); картинки вставляются из буфера и перетаскиванием файлов и хранятся внутри файла. Обводки (внутри / по центру / снаружи); эффекты: тень, внутренняя тень, размытие слоя и фона, шум; режимы наложения.
- Слои: дерево, переименование, скрытие, закрепление, перетаскивание; страницы.
- Свойства: поля с выражениями (`120/3`, `+10` для каждого объекта), прокрутка значения перетаскиванием подписи, «Смешанное» для разных значений.
- Компоненты: создание (Mod+Alt+K), экземпляры из панели «Ресурсы» (Alt+2), Alt+перетаскиванием и вставкой; переопределения, которые не теряются при правке компонента, смене варианта и копировании; наборы вариантов; свойства «текст», «видимость», «замена»; сброс, замена и отделение экземпляра (Mod+Alt+B).
- Стили цвета (цвет, градиент, изображение), текста и эффектов: кнопка ⁘ в разделах «Заливка», «Обводка», «Текст», «Эффекты»; правка стиля меняет все слои сразу; отделение, замена во всём файле, выделение слоёв со стилем; список стилей — в правой панели, когда ничего не выделено.
- Переменные: коллекции с режимами (например, светлая и тёмная тема), цвета, числа, строки и логические значения, ссылки между переменными; таблица переменных (палитра команд → «Таблица переменных» или кнопка в правой панели) с правкой как в Excel и вставкой из него; привязка полей кнопкой ⬡ у поля; режим выбирается у страницы, фрейма, группы или экземпляра; экспорт и импорт W3C Design Tokens.
- Точность: Alt — расстояния до соседнего слоя или краёв родителя; линейки (Shift+R) и направляющие (тянуть из линейки, двойной щелчок — точная позиция, обратно в линейку — удалить); сетки раскладки во фреймах (Ctrl+G); привязка к направляющим, сеткам, пикселям и равным интервалам; пиксельная сетка при большом увеличении; пипетка (I); обводка по сторонам, пунктир, концы и стыки; «Аккуратно расставить» (Ctrl+Alt+T).
- Секции (Shift+S или «Обернуть в секцию» в меню): области страницы с названием, цветом и статусом «В работе / Готово к разработке / Завершено». Внутри секции всё выделяется как на странице, пустое место секции работает как холст (рамка выделения), секцию выбирают по названию. Нарисованная или растянутая секция забирает слои, которые оказались целиком внутри.
- Слои: поиск и фильтр по типу и статусу, выделение диапазона с Shift; несколько файлов и список файлов (Mod+O).
- Прототипы: вкладка «Прототип» в правой панели, связь перетаскиванием синего «+» на экран, стрелки на холсте, потоки, просмотр поверх редактора или в новой вкладке (оверлеи, прокрутка с закреплёнными и липкими слоями, «Изменить на» для интерактивных компонентов; переменные и условия с выражениями вроде `{Счётчик} + 1`, отладчик (D); рамки iPhone, Pixel, iPad, MacBook; переходы с анимацией — растворение, умная анимация, въезд, сдвиг и другие, кривые и пружины; «Назад», ссылки, триггеры по нажатию, наведению, времени и клавише; стрелки ← → по экранам, R — заново).
- Сервер: регистрация и вход, файлы на сервере (открываются с любого устройства), работа без входа как раньше, перенос файлов из браузера на сервер. Свой HTTP-сервер и хранение в файлах на диске, без внешних пакетов.
- Совместная работа: правки соавторов сразу у всех, их курсоры и выделения; клик по аватару — наблюдать за человеком; спотлайт — все наблюдают за вами (палитра команд); чат курсором — `/` над холстом.
- Экспорт в PowerPoint: кнопка с экраном на панели инструментов или «Файл → Экспорт в PowerPoint» — фреймы становятся слайдами, текст остаётся редактируемым текстом.
- Отмена и повтор только своих действий; непрерывные жесты — один шаг отмены.
- Палитра команд `Mod+K` с поиском в неправильной раскладке; горячие клавиши работают в русской раскладке.
- Копирование и вставка (в том числе между вкладками), группы, фреймы, выравнивание и распределение, порядок слоёв.
- Автосохранение в браузере (IndexedDB), открытие и сохранение файла в открытом формате JSON, экспорт PNG / JPG / WebP / SVG / векторный PDF (текст выделяется), настройки экспорта на слое, ⇧⌘E — всё отмеченное в ZIP; копирование как PNG и SVG; импорт SVG вставкой и перетаскиванием.

Журнал ошибок и замечаний — в [docs/BUGS.md](docs/BUGS.md). Список требований ТЗ и их статус — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Структура

```
packages/
  core/      модель документа: узлы, операции, CRDT-правила, транзакции, отмена, формат файла
  geometry/  матрицы, прямоугольники, индекс, выражения, кривые Безье, булевы операции
  layout/    auto layout (flex), ограничения, группы, разметка текста, контуры слоёв
  components/ компоненты, экземпляры, варианты, синхронизация и переопределения
  render/    граф сцены, вьюпорт, Canvas 2D-рендерер, экспорт
  editor/    редактор: инструменты, привязки, панели, команды, хранение
apps/web/    точка входа веб-приложения
tools/       собственные dev-сервер и сборщик
docs/        архитектура, решения (ADR), дорожная карта
types/       минимальные декларации встроенных модулей Node для проверки типов
```

Архитектура описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
