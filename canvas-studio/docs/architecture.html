Устройство Симметрики

Монорепозиторий без внешних runtime-зависимостей — макеты, доски и схемы в одном редакторе.

Три вида файлов

fileKind в корневом узле документа
DESIGN · Макет

Пиксель-перфект вёрстка, компоненты, переменные, авто-раскладка, прототипы.

BOARD · Доска

Стикеры, фигуры с текстом, связи, штампы, разделы. Таймер, голосование, маркер.

DIAGRAM · Схема

Майнд-карты, блок-схемы, дерево по тексту. Движок DocPlan, экспорт SVG.

Ключевые пакеты

packages/core

Документ и операции

CRDT-подобная модель: три операции (create/set/move), часы Лэмпорта, дробные индексы порядка. Слияние без конфликтов — «последняя запись побеждает» по свойству.

document.tsops.tsmerge.tsschema.tsstore.ts
packages/render

WebGL2-рендер

Тайлы 256 px, каждый — Canvas2D-текстура в WebGL2. Семейства масштабов через ¼ октавы. При повреждении — перерисовка только затронутых тайлов. ?gpu=0 — fallback.

canvas-renderer.tsscene.tsviewport.tsfont-file.ts
packages/components

Конвейер транзакции

После каждой правки: стили → переопределения экземпляров → синхронизация → доска → auto layout. Записывается в той же транзакции — один шаг отмены.

board.tsinstances.tsstyles.tsvariables.ts
packages/layout

Auto layout

Повторяет CSS Flexbox (FIXED / HUG / FILL / FR / %). Ширины раньше высот. Текст измеряется Canvas2D в браузере, детерминированным приближением в тестах.

engine.tstext-measure.tsconstraints.ts
packages/geometry

Геометрия

Матрицы 2×3, прямоугольники, булевы операции (union/subtract/intersect через booleanRegions), векторные сети, переменная обводка.

matrix.tsboolean.tsnetwork.tsshapes.ts
packages/server

Сервер

Node.js без фреймворков. REST API + WebSocket для live-комнат. Хранение в JSON-файлах на диске. Версии, ветки, команды, комментарии, почта SMTP Beget.

api.tslive.tswebsocket.tsstorage.tsversions.ts
packages/diagrams

Движок схем

Вендорный движок DocPlan (vendor/) — майнд-карты, дерево, блок-схемы. Генерируется в engine.js через tools/diagrams-engine.mjs. Экспорт SVG.

engine.jsvendor/
packages/editor/src/fig

Импорт Figma (.fig)

Собственный парсер без зависимостей: zstd-распаковка, kiwi-десериализация, конвертация в схему. Компоненты, векторные сети, auto layout, переопределения.

zstd.tskiwi.tsconvert.tsarchive.ts
